# 网格识别人工对照实验

这个实验页用于人工比较：

- 当前网页实际使用的自动识别流程；
- “主导晶格共识”实验算法保留的五个候选；
- 已知人工基准，以及格点占用、格内主色、连续格线、中心结构和主体覆盖等证据。

实验页会由 `npm run sync:static` 一并复制到 `public/recognition-lab`，
因此会随 Cloudflare Pages 的普通生产构建发布。首页底部提供入口，
实验页也可以返回主应用。

## 启动

```powershell
npm run lab
```

然后访问：

<http://127.0.0.1:4173/recognition-lab/index.html>

如果只想重新同步实验文件：

```powershell
npm run sync:lab
```

## 判读顺序

1. 检查细网格是否与真实豆格的边界、方向和相位吻合；
2. 检查黄色虚线是否包住完整主体；
3. 检查行列数；
4. 如果第一候选不准，依次切换其余候选；
5. 选择人工判断，再复制结果摘要反馈给开发者。

“旧算法”通过一个仅限 `localhost` / `127.0.0.1` 的调试桥接调用当前
`app.js` 内的真实流程。没有实验参数时、在线上域名中，该桥接不会启用。
