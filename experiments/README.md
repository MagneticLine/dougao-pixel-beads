# 网格识别人工对照实验

这个实验页用于人工比较：

- 当前网页实际使用的自动识别流程；
- “主导晶格共识”实验算法保留的五个候选；
- 已知人工基准，以及格点占用、格内主色、连续格线、中心结构和主体覆盖等证据。

页面中的“标注人工解”可以保存正确行列与四个外层角点。保存或导入人工解后，候选区会显示当前候选的行列误差、按单格归一化的角点误差、框交并比，以及最接近人工解的候选排名。这些指标用于判断算法改动是否真的提升，而不是只靠目测或微调五张图。

批量建立正式数据集时请使用独立的 `/annotation-tool/` 页面。它保留完整原图坐标、计算 SHA-256、记录场景与素材权利，并输出 `docs/recognition-dataset-schema.md` 定义的标准标注包；实验室内的旧标注器只用于快速核对现有五个案例。

实验页会由 `npm run sync:static` 一并复制到 `public/recognition-lab`，
因此会随 Cloudflare Pages 的普通生产构建发布。首页底部提供入口，
实验页也可以返回主应用。

## 启动

```powershell
npm run lab
```

然后访问：

<http://127.0.0.1:4173/recognition-lab/index.html>

如果只想重新同步实验文件：

```powershell
npm run sync:lab
```

## 判读顺序

1. 检查细网格是否与真实豆格的边界、方向和相位吻合；
2. 检查黄色虚线是否包住完整主体；
3. 检查行列数；
4. 如果第一候选不准，依次切换其余候选；
5. 选择人工判断，再复制结果摘要反馈给开发者。

“旧算法”通过隐藏的同源运行器调用当前 `app.js` 内的真实旧版流程。
该桥接只在带有实验参数，并且页面来自同源 `/recognition-lab/` 时启用；
本地开发环境仍允许直接调试。普通首页和跨站页面无法启用该桥接。
