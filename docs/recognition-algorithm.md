# 统一自动网格识别研究

## 目标与前提

算法不要求用户选择“像素图、成品照片、半成品照片或图纸”等模式。用户先通过裁剪表达目标，主要对象的外接区域应占裁剪后画面的 50% 以上。算法在内部生成多种网格假设，使用同一组证据评分并选择主导结果。

这个前提仍允许：

- 纯色、透明、纹理或杂乱背景；
- JPEG 压缩、模糊、文字和水印；
- 光照渐变、反光、阴影和轻度透视；
- 熨烫后不明显的接缝；
- 未熨烫拼豆的孔洞与立体边缘；
- 少量附件或干扰物。

如果没有任何候选网格获得超过约一半画面的连贯支持，算法应降低置信度并建议用户裁得更紧，而不是输出一个看似确定的错误答案。

## 为什么不再采用硬场景分类

五类图片的表象不同，但目标都来自一个二维方格晶格。可观察证据主要有三类：

1. 颜色块、格线和接缝形成的边界或角点；
2. 拼豆孔洞、豆粒中心和重复局部结构形成的中心点；
3. 正确划分后，单格内部应存在占主导的稳定颜色。

这些证据的强弱会随图片变化，但不要求先知道图片属于哪一类。算法可以同时计算所有证据，再根据各证据自身的信噪比调整贡献。

## 当前实验观察

所有周期均是在最长边缩放到 560 像素后的实验坐标，不是原图像素或最终行列数。

| 素材 | 接近正确的候选 | 主要竞争项 | 失败原因 |
|---|---:|---:|---|
| 规则像素图 | `19 / 0°` | `9.5`、`38` | 半格与双格谐波 |
| 杂乱背景像素对象 | `8 / 0°` | `16` | 阴影和白边产生双格候选 |
| 熨烫成品 | `约 15 / 4°` | `约 29.5` | 接缝弱，双格候选接近 |
| 带孔拼豆 | `约 28.5 / 10°` | `20 / 54°` | 对角线会产生间距为 `p / √2` 的棋盘子网格 |
| 带文字图纸 | `约 15 / 0°` | `6`、`30–40` | 字符笔画制造短周期，图案块制造长周期 |

只取自相关或投影的最高峰会稳定地选错其中若干案例。实验表明，加入格点占用率、格内主导色、连续格线和中心响应后，正确基本格可以超过这些别名候选。
当前实验版中，五张图的人工参考格距与方向都已排到第一候选；边界结果依次为 `17 × 25`、`26 × 21`、`29 × 29`、`15 × 14`、`29 × 34`。其中第二、第三张还没有完整人工真值，不能仅凭数字宣布正确。

## 建议算法：主导晶格共识

### 1. 多尺度预处理

- 将分析图限制在约 560–720 像素最长边，最终坐标再映射回原图；
- 使用亮度与颜色梯度降低整体光照变化的影响；
- 使用局部中心—周围响应突出孔洞、豆粒中心和小型重复结构；
- 保留一份原始颜色图，用于后续格内主导色验证。

研究上，使用梯度削弱光照项、从重复局部特征提出晶格基向量，再通过单应性进行初步矫正，是近规则纹理检测中的成熟路线：

- <https://www.cv-foundation.org/openaccess/content_iccv_2015/papers/Liu_PatchMatch-Based_Automatic_Lattice_ICCV_2015_paper.pdf>
- <https://sites.psu.edu/lpac/lattice-detection/>

### 2. 统一候选生成

候选不是“场景模式”，而是若干几何假设：

```text
候选 = {两个晶格方向、两个格距、相位、旋转、初始支持区域}
```

候选来源可以并行存在：

- 边界和角点的模相位集中度；
- 中心点或孔洞的位移投票；
- 局部自相似块的位移候选；
- 梯度投影或自相关峰。

每发现一个周期 `p`，必须主动加入并比较：

- `p / 2` 与 `2p`；
- 旋转 45°、周期 `p / √2` 的对角子网格；
- 旋转 45°、周期 `p√2` 的对角超网格。

这比在结果出来后用固定阈值“修正倍频”更可靠。

### 3. 共识评分

每个候选统一计算以下指标：

| 指标 | 作用 |
|---|---|
| 模相位集中度 | 特征是否反复落在相同格内位置 |
| 已解释特征比例 | 候选是否覆盖了主要图像证据 |
| 预测格点占用率 | 排除只占奇偶格的半格或对角子网格 |
| 格内主导色比例 | 排除把多个真实格合并成一个大格的候选 |
| 连续格线支持 | 对图纸、规则像素块和可见接缝有效 |
| 中心晶格支持 | 对带孔拼豆和明显豆粒中心有效 |
| 最小描述长度项 | 避免无限偏好更细的小格 |

连续格线和中心晶格不做硬切换。算法选取当前图片中可靠度更高的证据，同时保留另一项作为弱证据。

### 4. 从仿射格到透视格

粗检测先寻找旋转和近似格距，再将晶格点赋予整数坐标。使用鲁棒拟合估计从理想方格到图片的单应性，剔除背景纹理和错误点。随后在矫正空间内重新测量周期、相位和格内颜色。

最后直接优化四角框与行列数，而不是只允许初始框在一格范围内微调。四角、格距和行列必须属于同一个联合模型。

### 5. 支持区域与边界

在矫正后的格坐标中生成逐格支持图：

- 该格是否有稳定主导色；
- 是否存在豆粒中心或孔洞；
- 四周是否有合理边界；
- 是否与相邻格保持相同晶格相位。

边界不再由单个“最大连通区”决定，而是让多种通用证据分别提出矩形候选：

- 综合逐格支持、中心结构、前景颜色和边缘结构的连通区域；
- 晶格共识点的整数坐标范围；
- 水平与垂直连续格线的有效区间；
- 行列投影及低证据外圈的收缩结果；
- 图纸外侧成对标注带所形成的强—弱过渡。

这些候选再用同一套覆盖先验、内部支持、外圈反证、证据保留率和边界线响应评分。这样规则像素图可由综合支持胜出，带孔拼豆可由孔洞晶格点范围胜出，带坐标文字的图纸则可以排除标号行列，同时保留图纸内部的空白格。

### 6. 置信度

高置信结果至少应满足：

- 第一候选明显高于第二候选；
- 在不同缩放层级下格距和行列数稳定；
- 主导支持区域接近或超过画面一半；
- 单应性矫正后的格子接近方形；
- 大部分格内存在稳定主导色。

否则界面应保留自动结果，但明确提示重新裁剪或手动校准。

## 实现顺序

1. 已完成仿射晶格候选、谐波共识评分和倍频反证；
2. 已用五张实验图固定格距、方向和第一轮人工反馈；
3. 已加入亚像素相位校正和多假设行列边界恢复；
4. 下一步补齐人工真值、裁剪扰动回归和四角单应性细化；
5. 最后替换现有 `像素 / 成品 / 自动` 三分支，对用户只保留自动识别。

人工真值至少应包含正确行列数和四个外层网格角点。只有行列数时，无法发现“数量正确但整体平移半格”或透视边缘错位。验证时还应对裁剪边缘、缩放、轻度模糊和 JPEG 压缩做扰动，避免算法只适配五个固定裁剪。

当前 `recognition/dominant-lattice-core.mjs` 与 `recognition/recognition-image-core.mjs` 已实现上述仿射阶段；单应性透视细化尚未实现。

## 主应用接入

主应用优先调用共享的混合识别核心，同时保留旧算法作为异常、无候选或低置信度时的回退。实验室显式调用旧算法用于对照，因此主应用升级不会污染旧版基线。

裁剪时会额外生成一份最长边 560 像素的未二次压缩分析图。工作图仍按原格式保存；识别核心使用分析图，避免 JPEG 再编码制造对角伪网格或改变主体边界。桌面端和移动端使用相同的分析尺寸与候选点上限，确保同一张图片不会仅因屏幕宽度不同而得到不同结果。
