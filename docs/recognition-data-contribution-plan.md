# 识别样本自愿贡献规划

## 目标

在不改变“图片默认只在本机处理”的前提下，允许愿意帮助改进算法的用户主动提交一份可复核样本。该能力不与导出图纸绑定，也不会在后台静默采集。

## 当前阶段

实验室已经支持本地导入、导出人工基准数据包。数据包包含：

- 原图文件名、尺寸和 SHA-256 指纹；
- 裁剪区域、行列数和四角坐标；
- 当前算法候选、置信度和人工备注；
- 数据格式版本与算法版本。

默认数据包不包含图片内容，也不会发起网络请求。它现在用于人工验证和离线回归测试。

## 未来交互

线上贡献应是一个独立动作，例如实验室中的“自愿贡献这个样本”，不能藏在“导出图纸”“保存工程”等常用操作里。

提交前必须展示确认页，让用户看到：

1. 将要上传的裁剪图预览；
2. 行列数、四角坐标、算法候选和备注；
3. 是否包含原始裁剪图；
4. 用途、保存期限和删除方式；
5. 明确的“提交”与“取消”按钮。

撤销同意后不应继续上传；关闭页面、网络失败或超时均不能影响本地导出。

## 两种贡献等级

### 只提交参数

包含人工框选、行列数、候选分数、耗时、图片尺寸和算法版本，不包含图片像素。

这类数据适合统计倍频误判、候选排序和性能分布，但通常不足以复现新的视觉问题。文件哈希也不能被宣传为“匿名”；它仍应按用户数据谨慎处理。

### 提交可复核样本

在单独勾选同意后，上传裁剪后的图片以及对应人工基准。只上传用户在裁剪工作区确认的区域，不上传原文件之外的设备信息、文件路径、剪贴板内容或相册信息。

这是改进边界、透视、光照和孔洞场景最有价值的数据，但必须有更明确的授权、保存期限和删除入口。

## 建议技术方案

Cloudflare Pages 保持静态站点；未来单独增加同源 Pages Function 作为提交接口：

- Pages Function：校验格式、大小、频率和用户确认令牌；
- R2：保存明确同意上传的裁剪图与数据包；
- D1：保存样本索引、算法版本、审核状态和删除令牌；
- Turnstile 或速率限制：降低自动滥用；
- 管理端：只允许审核人员访问，记录导出与删除操作。

接口需要限制 MIME、像素尺寸和数据包版本，拒绝 SVG、HTML、可执行内容和超大文件。客户端生成随机删除令牌；服务端只保存其哈希，用户可凭原令牌申请删除。

## 评估指标

验证集不只比较“行列数是否相等”，还应记录：

- 列数、行数绝对误差；
- 四角平均像素误差；
- 框选区域交并比；
- 格线相位误差占单格的比例；
- 正确候选在前 1、前 3、前 5 中的命中率；
- 桌面与移动设备的耗时、峰值内存和回退率。

训练集、调参集和最终验证集应分开。人工基准一旦进入最终验证集，就不再用来调当前阈值，避免对少量样例过拟合。

## 上线前清单

- 产品文案仍明确写明“默认不上传图片”；
- 贡献入口默认关闭，且没有预勾选同意；
- 能在提交前预览全部待上传内容；
- 有数据用途、保存期限、许可范围和删除说明；
- 有大小限制、速率限制、内容校验和访问审计；
- 能区分算法版本、数据格式版本与人工基准版本；
- 先用内部测试端点验证，再决定是否开放给普通用户。
