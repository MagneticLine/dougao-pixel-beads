# 拼豆识别数据集工作区

这里记录识别算法需要的数据结构与收集规则。当前仓库只保留已经进入实验室的开发样本；真正的数据集仍在建设中。

## 四类核心场景与视觉标签

1. 像素画；
2. 拼豆图纸；
3. 已熨烫的拼豆成品照片；
4. 未熨烫、带孔洞和底板凸点的半成品照片。

素材类型只放在主场景中。有无网格、网格深浅、透明/纯色/复杂背景、文字、色号、水印、压缩、模糊、透视和光照等可观察特征使用可组合的视觉标签记录。这样同一类像素画可以直接比较“无网格、明显网格、淡网格”条件下的识别差异。

目标规模写在 `experiments/recognition-fixtures.json`：

- 核心真实集：60–100 张；
- 合成退化集：200–500 张；
- 锁定测试集：20–30 张。

现在的五张图已经参与过算法观察和调参，所以只能算 `development`，不能冒充从未看过的锁定测试集。

## 标注工具与规范

打开网站的 `/?mode=annotation` 页面，可以一次导入多张完整原图，标注四个外层格线角点、行列数、主场景、视觉标签、数据划分和素材权利状态，再导出不含图片本体的标准 JSON。

完整的字段定义、坐标语义、目录结构、划分防泄漏和人工质检流程见：

- `docs/recognition-dataset-schema.md`

每张图需要记录：

- 主场景、视觉标签、开发/验证/锁定测试划分；
- 原始作者或来源链接、获取日期、文件哈希；
- 授权或使用状态；
- 完整原图的浏览器解码宽高，且 `crop` 固定为 `null`；
- 正确行列数；
- 按左上、右上、右下、左下顺序排列的四个外层网格角点；
- 可选备注：无法由标准视觉标签完整表达的特殊情况。

JSON 通过原始文件的 SHA-256 与图片配对。完整四角真值很重要：只有行列数无法发现“数量正确但整体平移半格”的错误。

## 版权与隐私边界

来源与再分发权不明确的小红书、百度或 Google 图片只能放入被 Git 忽略的 `datasets/private/`，用于本机私有测试，不得提交到公开仓库。至少记录作者、链接、获取日期与文件哈希。

公开样本优先使用：

- 自己拍摄；
- 作者明确授权；
- CC0、CC BY 或其他允许当前用途和再分发的素材。

当前仓库已有五张实验图的历史授权信息尚待复核，清单将其标为 `review-required`，不会把它们声明成可自由再分发的数据集。

## 合成退化

具有已知逻辑分辨率的像素画可以自动生成真值完全确定的派生样本，包括模糊、JPEG 压缩、整数与非整数缩放、旋转、透视、光照渐变和复杂背景。合成数据用于覆盖扰动，不代替真实照片。

运行以下命令可检查清单结构、四类场景覆盖、标签合法性、锁定集真值要求和素材文件是否存在：

```powershell
npm run check:recognition-data
```
